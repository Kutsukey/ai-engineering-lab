# ai-engineering-lab

## Bu repo ne
Öğrencilik boyunca yaptığım bootcamp çalışmalarını, eğitim kodlarını ve denemeleri bu repoda tutuyorum. Her şey öğrenme amaçlı.

## Klasörler
code/bootcamp: Kendime hazırladığım programın ilk fazı. 14 günlük (week01 ve week02) Python ve C++ çalışmaları var. Python tarafında Big-O, binary search, stack, linked list, matris işlemleri, recursion, selection ve quick sort, hash table, BFS, Dijkstra, greedy, 0/1 knapsack ve sıfırdan KNN yazdım. C++ tarafında pointer ve reference, enum, struct, class, vector, array, move semantics, template sınıf, virtual fonksiyonlar ve function overloading var.

code/cp: Competitive programming çözümlerim. cses klasöründe 28 çözüm, codeforces klasöründe 3, alpoc'26 klasöründe 6 çözüm var. Graf, MST ve DSU, greedy, prefix sum ve binary search vs.

code/ml: Makine öğrenmesi çalışmalarım. 01_tensors içinde PyTorch tensör denemeleri, 02_gradient_descent içinde sıfırdan gradient descent (saf Python ve PyTorch), sklearn_breast_cancer içinde scikit-learn ile sınıflandırma var. Her klasörün kendi README'si var.

## Durum
Bootcamp'in ilk fazı (Python algoritma ve C++ temelleri) bitti, sonrasında projelere yöneldim. ml klasörü devam ediyor.

## Çalıştırmak için
Python 3.13 ve şu paketler: torch, scikit-learn, pandas, numpy. C++ 20 yeterli.
