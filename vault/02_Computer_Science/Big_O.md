### Nedir
Algoritmanın veri büyüdükçe nasıl davranacağını gösterir
Gerçek çalışma süresi değil büyüme hızını ifade eder

#### O(1)  
- Array index  
- HashMap / Dict erişimi  
  
#### O(log n)  
- Binary Search  
  
#### O(n)  
- Linear/Simple Search  
  
#### O(n log n)  
- Merge Sort  
- Quick Sort  
  
#### O(n²)  
- Bubble Sort  
- Selection Sort  
- İç içe iki döngü  
  
#### O(2ⁿ)  
- Naive Recursive Fibonacci

#### O(n!)
- Salesperson problem
